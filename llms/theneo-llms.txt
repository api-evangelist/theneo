# Theneo

> Theneo is an AI-powered API documentation platform and developer portal where humans and AI agents ship API docs together. Teams generate complete documentation from any API spec, then publish API references, user guides, changelogs, and private per-customer portals — with real-time co-editing, an Ask AI answer bot, MCP server support, and llms.txt built in. Trusted by 18,000+ teams from startups to the Fortune 500, and backed by Y Combinator, Mercury, and Atlassian. SOC 2 Type II, ISO 27001 & 9001, and GDPR compliant, with EU data residency and self-hosting available.

## Product
- [Theneo home](https://www.theneo.io): The all-in-one developer portal for API references, guides, changelogs, and private customer portals.
- [Developer Portal](https://www.theneo.io/developer-portal): Authenticated, branded portals where each customer signs in and sees only the APIs, guides, and SDKs that apply to them.
- [API Reference](https://www.theneo.io/api-reference): Interactive, auto-generated API reference docs from an OpenAPI/Swagger spec.
- [API Explorer & Changelog](https://www.theneo.io/api-changelog): In-browser API testing plus automated changelogs that flag breaking changes in your API.
- [Ask AI](https://www.theneo.io/ask-ai): AI answer bot that gives developers direct answers from your docs instead of search results.
- [Enterprise](https://www.theneo.io/enterprise): Security, compliance, SSO, audit logs, white-label, and self-hosting for regulated and growing teams.
- [Security](https://www.theneo.io/security): SOC 2 Type II, ISO 27001 & 9001, GDPR, EU data residency, and self-hosting details.
- [Pricing](https://www.theneo.io/pricing): Plans and pricing tiers.
